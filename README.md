# Zwyntar

Невеликий проєкт з даними та візуалізаціями YouTube-каналу **Zwyntar**: скрипт збирає статистику через YouTube Data API v3, зберігає її в Excel, а Tableau дашборд та набір HTML-сторінок показує ці дані у вигляді інтерактивних готичних візуалізацій.

Дані зібрано **10.10.2026**: 48 відео, 14 плейлистів, 12 релізів. Усі дати — UTC.

## Як користуватися

**Візуалізації.** Достатньо відкрити будь-яку `Zwyntar — *.html` сторінку в браузері. Дані вбудовані прямо в код (`const DATA = ...`), тож збірка чи сервер не потрібні. Із зовнішніх ресурсів сторінки підвантажують лише шрифти Google Fonts (EB Garamond, Ruslan Display), а `index.html` — плеєр YouTube, тому для них потрібен інтернет.

**Оновлення даних.**

1. Встановіть залежності: `pip install requests python-dotenv openpyxl`.
2. Створіть файл `.env` із ключем: `YOUTUBE_API_KEY=ваш_ключ`.
3. Запустіть: `python zwyntar_youtube_data.py`.

Поведінку скрипта задають прапорці на початку файлу: `ONLY_MUSIC` (лише відео з музичною тематикою), `COLLECT_COMMENTS` (рахувати коментарі по датах) та `INCLUDE_REPLIES` (враховувати відповіді на коментарі). Збір коментарів витрачає квоту API: 1 одиниця на кожні 100 коментарів.

## Джерело та обмеження

- Дані: YouTube Data API v3, канал Zwyntar (ID `UCio0I8HBJ7rWc7tk17rYqHw`).
- Тип відео (запис, відео чи концерт) визначено за назвою та джерелом, а не з даних YouTube.
- Тип релізу — припущення: один трек це сингл, більше — альбом або EP.
